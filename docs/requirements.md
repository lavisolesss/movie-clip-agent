# 需求說明

## 這是什麼
一個在我自己電腦上執行的 Discord agent。只要它開著，我 Discord Server 裡指定頻道的任何人，傳一張影視片段的截圖，或打出一句台詞，它就會找出這是哪一部作品、建檔，再回覆上傳者。agent 關掉就不處理。

## 為什麼要做
我常在網路上（短影音、迷因、社群貼文）看到某些令人感興趣的影視片段或台詞金句，但貼文沒有附上作品名稱，自己用關鍵字搜尋也常常找不到。我想要一個「丟進去就幫我查」的地方，而且查過的東西會留下紀錄，之後想看那部作品時找得回來。

## 誰會用
我自己的 Discord Server 裡、那個指定頻道的任何人，用手機或電腦都可以傳。

## 使用的流程
1. 有人在頻道裡傳一張影視截圖，或直接打出一句台詞（也可以兩個一起）
2. agent 收到，先回一個「處理中」的提示
3. agent 判斷：是不是影視畫面、出自哪部作品（片名、原文片名、年份、類型）、是哪一段劇情、有把握的程度
4. agent 把結果記下來、把截圖存起來
5. agent 回覆上傳者這次的結果，並附上「今天頻道裡已找到幾部作品」

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 日期時間
- 上傳者
- 查詢方式（截圖、文字、截圖+文字）
- 查詢的台詞或文字
- 辨識結果（找到、找不到、不是影視畫面）
- 作品名稱
- 原文名稱
- 年份
- 類型（電影、影集、動畫……）
- 片段說明
- 信心程度
- 當日已找到作品數
- 截圖存放位置

截圖另外存進一個資料夾，檔名用「日期時間 + 作品名稱」。

## 找不到、或不是影視畫面的時候
- 找不到：一樣要回覆上傳者「沒有找到確定的作品」，並說明原因或最接近的猜測。也要建檔、存截圖。
- 不是影視畫面（例如貓的照片）：回覆「你傳的不是影視畫面，是某某東西」。也要建檔、存截圖，辨識結果寫「不是影視畫面」。

## 畫面上 / 回覆上要有
- 收到時先有「處理中」的提示
- 處理完回覆：作品名稱、原文名稱、年份、類型、片段說明、信心程度、今天已找到的作品數
- 註明結果是 AI 判斷的，可能有誤

## 不需要的
- 註冊、登入
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- 影片檔的分析（先用截圖代替）
- 提供線上觀看的連結

## 技術上我知道的
- 用 Python 3.12 + uv
- 截圖和台詞用 `claude -p` 在我這台電腦上處理，可以讓它上網搜尋來查證
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`
